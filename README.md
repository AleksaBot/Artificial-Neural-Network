This project demonstrates the implementation of a simple artificial neural network (ANN) from the ground up using Python and NumPy. Designed as an educational tool, it provides insights into the foundational concepts of neural networks, including forward propagation, backpropagation, and training processes without relying on high-level machine learning libraries.

🧠 Overview
The notebook guides readers through:

Data Preparation: Loading and preprocessing datasets suitable for training.

Network Architecture: Constructing a feedforward neural network with customizable layers and activation functions.

Forward Propagation: Calculating outputs based on inputs and current weights.

Backpropagation: Computing gradients to update weights and biases.

Training Loop: Iteratively improving the network's performance over multiple epochs.

Evaluation: Assessing the model's accuracy and visualizing performance metrics.

📝 Features
Customizable Architecture: Modify the number of layers, neurons, and activation functions to experiment with different network configurations.

Educational Insights: Inline comments and markdown cells explain each step, making it suitable for learners.

Visualization: Graphs and plots to visualize loss curves and accuracy over epochs.

🔍 Usage
After setting up, run each cell in the Project.ipynb notebook sequentially. The notebook is structured to first introduce the theory, followed by code implementations and visualizations.
